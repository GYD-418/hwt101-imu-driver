# HWT101 IMU 驱动封装库

维特智能 HWT101 系列陀螺仪（IMU）的 UART 协议解析封装函数。

## 文件说明

```
├── hwt101.c   # 协议解析实现（帧头校验、数据解算）
└── hwt101.h   # 对外接口
```

## 使用方式

将 `hwt101.c / hwt101.h` 加入工程，串口中断接收数据后调用解析函数即可获取：

- 偏航角 / 俯仰角 / 横滚角（Yaw / Pitch / Roll）
- 角速度、加速度（视模块配置）

## 适用平台

任意带 UART 的 MCU（STM32 / ESP32 / MSPM0 等），纯 C 实现，无平台依赖。
